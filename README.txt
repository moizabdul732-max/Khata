KHATA APP — install guide (free)

1) Free hosting (GitHub Pages)
   - github.com par free account banayein -> New repository (naam: khata) -> Public
   - "Add file > Upload files" se is folder ki SAARI files upload karein
     (index.html, manifest.webmanifest, sw.js, aur icons folder)
   - Settings > Pages > Branch: main, Folder: /(root) > Save
   - 1-2 min baad link milega: https://USERNAME.github.io/khata/

2) Phone par install
   - Android: Chrome me link kholein -> menu (3 dots) -> "Install app" / "Add to Home screen"
   - iPhone: Safari me link kholein -> Share -> "Add to Home Screen"
   - Pehli baar internet ON rakhein (fonts + CSV library save hoti hain), phir offline bhi chalega.

3) Updates
   - index.html badalne par sw.js me VERSION = 'khata-v2' kar dein, phir dono files dobara upload karein.

4) Data safety
   - Data phone me hi save hota hai (localStorage). App uninstall / browser data clear = data delete.
   - Accounts/Vouchers ke CSV export regularly karte rahein.

5) Optional APK (Android)
   - pwabuilder.com -> apna link daalein -> Package for stores -> Android -> Download
   - APK direct share ho sakti hai; Play Store par daalne ke liye $25 one-time fee lagti hai.
